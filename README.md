# Каталог фильмов

SPA на **React**, **TypeScript** и **Material UI**: каталог фильмов с API [ПоискКино](https://poiskkino.dev/documentation) (Kinopoisk API).

## Требования

- Node.js 18+

## Переменные окружения

1. Скопируйте `.env.default` в файл `.env` в корне проекта.
2. Укажите ключ API в переменной `VITE_API_KEY` (получить можно на [poiskkino.dev](https://poiskkino.dev/documentation)).

Пример `.env`:

```env
VITE_API_KEY=ваш_ключ
```

## Установка и запуск

```bash
npm install
npm run dev
```

Приложение откроется по адресу, который покажет Vite (обычно `http://localhost:5173`).

## Сборка

```bash
npm run build
npm run preview
```

## Функциональность

- **Каталог** (`/`): список фильмов с подгрузкой по 50 записей при прокрутке; фильтры по жанрам (несколько), диапазону рейтинга Кинопоиска и года (от 1990); параметры отражены в query-строке URL.
- **Поиск** (поле в шапке): страница `/search?q=...` с такой же подгрузкой списка.
- **Карточка фильма** (`/movie/:id`): постер, название, описание, рейтинг, дата выхода, жанры.
- **Избранное** (`/favorites`): отдельная страница; добавление только после подтверждения в модальном окне; данные сохраняются в браузере.
- **Сравнение**: до двух фильмов; при выборе третьего первый сбрасывается; внизу экрана - таблица сравнения (название, год, рейтинг, жанры, длительность).

## Стек

- Vite, React 19, TypeScript
- React Router, Axios, Tanstack query
